Feira Livre

Sobre

Aplicação web com mapa interativo das feiras livres de São Paulo.

Esta aplicação utiliza os dados abertos das feiras livres disponibilizados pelo GeoSampa da Prefeitura de São Paulo, sob a licença CC BY-SA 4.0.
